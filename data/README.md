# Hospital Billing Dataset

## Dataset Overview

This project uses a synthetic hospital billing dataset for Data Engineering and analytics practice.

| Attribute | Details |
|---|---|
| Format | CSV |
| Source records | 1,010 |
| Columns | 20 |
| Usage | Hospital billing analytics |

## Dataset Contents

The dataset contains billing, patient visit, department, hospital branch, service, payer and payment information.

## Data Usage

The CSV is uploaded to a Databricks Unity Catalog Volume and processed through Bronze, Silver and Gold layers.

## Privacy

The raw dataset is not included in this GitHub repository.

No patient-level or sensitive information should be published.

## Source

The dataset was supplied as part of the Hospital Billing Analytics project materials.
