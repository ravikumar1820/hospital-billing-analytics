# Databricks SQL Pipelines

This folder contains the SQL transformation scripts used in the Hospital Billing Analytics project.

## Pipeline Files

| File | Description |
|---|---|
| `01_bronze.sql` | Raw data ingestion |
| `02_silver.sql` | Data cleaning and transformation |
| `03_gold.sql` | Business analytics |
| `04_data_quality.sql` | Data quality checks and reconciliation |

These scripts implement the Bronze, Silver, and Gold layers of the Medallion Architecture using Databricks SQL.
